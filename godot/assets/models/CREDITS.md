# 3D model assets

CC0 props under `models/<name>/<name>.gltf` (+ `.bin` and `textures/`), consumed
by `src/props.gd` via the REGISTRY const. Swapping a prop = replace the directory
or repoint the registry entry.

All models from https://polyhaven.com — CC0 1.0 Universal public domain, no
attribution required (recorded anyway). Downloaded 2026-10-16 via the PolyHaven
API at the smallest (1K) texture resolution.
